Capture to HTML — 스토어 스크린샷 템플릿

  1. 창 안에는 위키백과 화면이 이미 들어 있습니다(한국어 시트는 ko, 영어 시트는 en). 그대로 저장하면 됩니다. 화면을 갱신하려면 node store/shots/embed-shots.mjs.
  2. 다른 화면으로 바꾸려면 — PNG 나 저장한 HTML 파일을 끌어다 놓거나, 주소창에 URL 을 쓰고 Enter 를 칩니다. 다만 URL 로 띄운 사이트(iframe)는 PNG 저장 버튼에 담기지 않습니다 — 그 시트만 개발자도구로 찍으세요.
  3. 확장 팝업은 툴바 아이콘을 누른 모습으로 04 번 시트에 이미 얹혀 있습니다. 눌러서 저장 전 ↔ 저장 완료를 바꾸고, 상단 바 버튼으로 시트마다 켜고 끕니다. 영어·다크 모드는 node test/uishot.mjs ko,en 이 만든 PNG 를 팝업 위에 끌어다 놓으면 됩니다.
  4. 제목·설명·탭 이름·주소·칩은 클릭해서 바로 고칠 수 있습니다.
  5. 강조 사각형은 드래그로 옮기고, 모서리를 끌어 크기를 바꿉니다. 필요 없으면 강조 끄기.
  6. 다 되면 캡처: 크롬에서 개발자도구 → 해당 .sheet 요소 선택 → ⋮ → Capture node screenshot. 정확히 1280×800 으로 저장됩니다. (⌘⇧4 로 찍으면 레티나 때문에 2560×1600 이 되니 주의)
