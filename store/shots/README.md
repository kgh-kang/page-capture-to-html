# 스토어 스크린샷 만들기

`template.html` 을 크롬에서 열면 1280×800 캔버스 5장이 나온다.

1. **화면 채우기** — 셋 중 하나
   - 주소창에 URL 을 쓰고 **Enter** → 그 사이트가 창 안에 그대로 뜬다.
     따로 캡처할 필요가 없고, 안에서 스크롤·클릭도 된다(공지 배너 닫기 등).
     단 `frame-ancestors` 로 임베드를 막는 사이트는 빈 화면이 된다 — 위키백과는 열린다
   - **저장한 HTML 파일**을 흰 영역에 끌어다 놓는다 → 확장의 결과물이 그대로 렌더된다
   - **캡처한 PNG** 를 끌어다 놓는다
2. **문구 고치기** — 제목·설명·탭 이름·주소·칩을 클릭해서 바로 수정
3. **색 바꾸기** — 상단 바에서 배경·포인트 색을 고른다
4. **강조 사각형** — 드래그로 위치를 옮긴다. 필요 없으면 끈다
5. **캡처** — 개발자도구에서 해당 `.sheet` 요소를 선택하고
   `⋮` → **Capture node screenshot**. 정확히 1280×800 으로 저장된다

> ⌘⇧4 로 찍으면 레티나 때문에 2560×1600 이 되고, 스토어 규격(1280×800)에 안 맞는다.
> 개발자도구 방식이 정확하다.

화면 대 화면 비교(원본 / 저장본)를 만들려면 한 장은 URL 로, 한 장은 저장한 HTML 로 채우면 된다.
