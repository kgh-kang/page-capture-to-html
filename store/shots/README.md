# 스토어 스크린샷 만들기

먼저 템플릿을 만든다. 완성본은 1.2MB 라 저장소에 두지 않는다.

```sh
node store/shots/build-template.mjs
```

`template.src.html`(27KB) 에 글꼴·팝업 UI·창 안 화면을 심어 `out/template.html` 을 뽑는다.
없는 소재는 알아서 만들어 온다 — 팝업은 `popup.html` 을 렌더해서, 창 안 화면은
`embed-shots.mjs` 로 받아서. 소재가 이미 있으면 그대로 쓴다.

만들어진 `out/template.html` 을 크롬에서 열면 1280×800 캔버스 열 장이 나온다.
**01–05 는 한국어, E1–E5 는 같은 내용의 영어판**이다. 스토어는 언어별로 스크린샷을
따로 올릴 수 있으니 필요한 것만 골라 저장하면 된다.

1. **창 안 화면** — 이미 그림으로 들어 있다. 창 크기(1104×482) 그대로 찍은 것이라
   확대·축소 없이 또렷하다. 그냥 저장하면 된다. **넣을 화면은 이 명령으로 바꾸고**,
   이어서 `build-template.mjs` 를 다시 돌린다:

   ```sh
   node store/shots/embed-shots.mjs                       # 기본값(위키백과 HTML 문서)
   node store/shots/embed-shots.mjs <주소>                 # 열 장 모두 이 화면으로
   node store/shots/embed-shots.mjs ko=<주소> en=<주소>    # 언어별로 따로
   node store/shots/embed-shots.mjs 저장한파일.html        # 확장의 결과물을 그대로
   node store/shots/embed-shots.mjs <주소> --scroll=400    # 찍기 전에 그만큼 내린다
   ```

   받은 화면은 `screens/{ko,en}.png` 로 남는다. 공지·정리 알림 상자는 찍기 전에 지운다. 확장으로 저장한 HTML 을 넘기면 **실제 결과물**이
   스크린샷에 들어가므로 가장 정직하다.
   - 다른 화면으로 바꾸려면 **PNG 나 저장한 HTML 파일**을 창 안에 끌어다 놓는다
   - **주소창에 URL 을 쓰고 Enter** 하면 그 사이트가 실제로 뜬다. 구도를 잡아 볼 때 편하지만
     iframe 으로 뜨는 것이라 `PNG 저장` 에는 안 담긴다 — 그때는 `화면 그대로` 를 쓴다
2. **확장 팝업** — 툴바 아이콘을 누른 모습으로 04 · E4 시트에 이미 얹혀 있다.
   눌러서 **저장 전 ↔ 저장 완료**를 바꾸고, 상단 바 버튼으로 시트마다 켜고 끈다.
   다크 모드로 바꾸려면 `node tools/uishot.mjs ko,en` 이 만든 PNG 를 팝업 위에 끌어다 놓는다
3. **문구 고치기** — 제목·설명·탭 이름·주소를 클릭해서 바로 수정
4. **색 바꾸기** — 상단 바에서 배경·포인트 색을 고른다
5. **강조 사각형** — 드래그로 위치를 옮긴다. 필요 없으면 끈다

## 저장 — 웹페이지 안에서 끝난다

**`PNG 저장`** — 시트 왼쪽 위 버튼은 그 한 장을, 상단 바의 **전체 PNG 저장**은 열 장을
한 장씩 차례로 내려받는다(`capture-to-html-01.png` … `capture-to-html-E5.png`).
편집한 그대로 1280×800 이 떨어지고 개발자도구를 열 필요가 없다.
여러 장을 받을 때 크롬이 "여러 파일을 다운로드하시겠습니까?" 하고 물으면 허용한다.

이 방식은 시트를 그림으로 다시 그리는 것이라 **다른 출처의 iframe 은 담기지 않는다**
(브라우저가 막는다). 미리 심어 둔 화면은 그냥 `<img>` 라 아무 문제 없다.

**`화면 그대로`** — 주소창으로 사이트를 띄웠다면 이쪽이다. 화면 공유 API 로 브라우저가
실제로 그린 픽셀을 받아 시트 영역만 잘라낸다. **iframe 이든 뭐든 눈에 보이는 대로** 담긴다.
누르면 크롬이 "탭을 공유할까요?" 하고 묻는데 **이 탭**을 고르면 된다.
상단 바의 **전체 화면 그대로**는 한 번만 묻고 열 장을 이어서 받는다.

조건이 하나 있다. **시트가 화면 안에 통째로 보여야 한다** — 브라우저 창이 1280×800 보다
작거나 확대가 100% 가 아니면 안내가 뜬다. 레티나에서는 배율만큼 크게 받아 1280×800 으로
줄이므로 오히려 더 또렷하다.

## 스토어가 받는 규격

> **1280×800 또는 640×400 · JPEG 또는 24비트 PNG(알파 없음)**

두 버튼 다 이 규격에 맞춰 파일을 직접 조립한다. 브라우저의 `canvas.toBlob` 은
무조건 알파가 붙은 32비트 PNG 를 내놓기 때문에, RGB 만 뽑아 PNG 청크를 손으로 쓴다.
그래서 언제나 정확히 **1280×800 · 24비트 · 알파 없음**이다.

**바깥 도구로 찍지 않는 게 좋다.** ⌘⇧4 든 개발자도구 캡처든 레티나에서는 화면 배율이
곱해져 2560×1600 으로 저장되고, 스토어는 "이미지 크기가 잘못되었습니다" 로 거른다.
굳이 그렇게 찍었다면 크기를 확인하고 1280×800 으로 줄여서 올린다.

화면 대 화면 비교(원본 / 저장본)를 만들려면 한 장은 URL 로, 한 장은 저장한 HTML 로 채우면 된다.
