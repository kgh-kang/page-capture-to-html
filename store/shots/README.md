# 스토어 스크린샷 만들기

`template.html` 을 크롬에서 열면 1280×800 캔버스 열 장이 나온다.
**01–05 는 한국어, E1–E5 는 같은 내용의 영어판**이다. 스토어는 언어별로 스크린샷을
따로 올릴 수 있으니 필요한 것만 골라 저장하면 된다.

1. **화면 채우기** — 셋 중 하나
   - 주소창에 URL 을 쓰고 **Enter** → 그 사이트가 창 안에 그대로 뜬다.
     따로 캡처할 필요가 없고, 안에서 스크롤·클릭도 된다(공지 배너 닫기 등).
     단 `frame-ancestors` 로 임베드를 막는 사이트는 빈 화면이 된다 — 위키백과는 열린다
   - **저장한 HTML 파일**을 흰 영역에 끌어다 놓는다 → 확장의 결과물이 그대로 렌더된다
   - **캡처한 PNG** 를 끌어다 놓는다
2. **확장 팝업** — 툴바 아이콘을 누른 모습으로 04 · E4 시트에 이미 얹혀 있다.
   눌러서 **저장 전 ↔ 저장 완료**를 바꾸고, 상단 바 버튼으로 시트마다 켜고 끈다.
   다크 모드로 바꾸려면 `node test/uishot.mjs ko,en` 이 만든 PNG 를 팝업 위에 끌어다 놓는다
3. **문구 고치기** — 제목·설명·탭 이름·주소를 클릭해서 바로 수정
4. **색 바꾸기** — 상단 바에서 배경·포인트 색을 고른다
5. **강조 사각형** — 드래그로 위치를 옮긴다. 필요 없으면 끈다

## 저장하는 두 가지 방법

**`PNG 저장`** — 시트 왼쪽 위 버튼은 그 한 장을, 상단 바의 **전체 PNG 저장**은 열 장을
한 장씩 차례로 내려받는다(`capture-to-html-01.png` … `capture-to-html-E5.png`).
편집한 그대로 1280×800 이 떨어지고 개발자도구를 열 필요가 없다.
여러 장을 받을 때 크롬이 "여러 파일을 다운로드하시겠습니까?" 하고 물으면 허용한다. 다만 **창 안에 iframe 으로 띄운 사이트는 담기지 않는다**
(다른 출처의 iframe 을 그림으로 옮기는 것은 브라우저가 막는다). 눌렀을 때 경고가 뜨는 게 그 이유다.

**개발자도구 → `.sheet` 선택 → `⋮` → Capture node screenshot** — iframe 까지 그대로 담긴다.
사이트 화면을 URL 로 띄웠다면 이쪽을 쓴다.

## 스토어가 받는 규격

> **1280×800 또는 640×400 · JPEG 또는 24비트 PNG(알파 없음)**

`PNG 저장` 버튼은 이 규격에 맞춰 파일을 직접 조립한다. 브라우저의 `canvas.toBlob` 은
무조건 알파가 붙은 32비트 PNG 를 내놓기 때문에, RGB 만 뽑아 PNG 청크를 손으로 쓴다.
그래서 언제나 정확히 **1280×800 · 24비트 · 알파 없음**이다.

**레티나 화면에서는 다른 방법이 규격을 벗어난다.** ⌘⇧4 든 개발자도구 캡처든 화면 배율이
곱해져 2560×1600 으로 저장되고, 스토어는 "이미지 크기가 잘못되었습니다" 로 거른다.
그쪽으로 찍었다면 파일 정보에서 크기를 반드시 확인하고, 2배로 나왔다면
미리보기 등에서 1280×800 으로 줄여서 올린다.

화면 대 화면 비교(원본 / 저장본)를 만들려면 한 장은 URL 로, 한 장은 저장한 HTML 로 채우면 된다.
