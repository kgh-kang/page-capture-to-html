Capture to HTML — 스토어 스크린샷 템플릿

  1. 아래 흰 영역(.viewport)에 캡처한 PNG 를 끌어다 놓으면 브라우저 창 안에 들어갑니다.
  2. 제목·설명·탭 이름·주소·칩은 클릭해서 바로 고칠 수 있습니다.
  3. 강조 사각형은 드래그로 옮기고, 모서리를 끌어 크기를 바꿉니다. 필요 없으면 강조 끄기.
  4. 다 되면 캡처: 크롬에서 개발자도구 → 해당 .sheet 요소 선택 → ⋮ → Capture node screenshot. 정확히 1280×800 으로 저장됩니다. (⌘⇧4 로 찍으면 레티나 때문에 2560×1600 이 되니 주의)
