# Page Capture to HTML

지금 화면에 **보이는 것만** 잘라서 단일 HTML 파일로 저장하는 크롬 확장.

SingleFile 같은 도구는 페이지 전체를, 그것도 `display:none` 으로 숨겨진 메뉴·모달·미사용 템플릿까지
전부 담는다. 이 확장은 반대로 **캡처를 누른 그 순간 뷰포트에 실제로 그려져 있던 것**만 남긴다.
애니메이션·hover·미디어쿼리·스크립트는 전부 사라지고, 그 순간의 모습이 그대로 굳는다.

## 설치

Chrome Web Store 를 거치지 않고 로컬에서 바로 쓴다.

1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택

툴바 아이콘 클릭 → **화면 저장**. 단축키는 `Alt+Shift+S`.

## 옵션

팝업 문구는 전부 **결과 중심의 일상어**로 쓴다. "뷰포트", "iframe", "오버레이" 같은 말은
쓰는 사람 머릿속에 없는 단어라서, 무엇이 어떻게 달라지는지로 바꿔 적었다.
주 선택은 하나뿐이고 나머지는 "자세한 설정"에 접어 둔다 — 실제로 매번 바꿀 만한 건 하나다.

| 팝업 문구 | 키 | 기본 | 하는 일 |
|---|---|---|---|
| 지금 화면만 / 페이지 전체 | `crop` | 지금 화면만 | 켜면 연 순간 딱 그 화면. 끄면 전체 높이를 유지한 채 안 보이던 내용만 비움 |
| 아무것도 안 눌리게 굳히기 | `freeze` | 끔 | 링크·입력·스크립트를 전부 끊어 **읽기 전용**으로 |
| 덮은 안내창 치우기 | `dropOverlay` | 끔 | 화면을 가린 모달·배너를 걷어내고 **그 아래 내용**을 저장 |
| 가려진 글자 빼기 | `occlusion` | 켬 | 무언가에 덮여 안 보이던 내용 제거 |
| 사진 넣기 | `images` | 켬 | 끄면 파일이 훨씬 가벼워진다 |
| 글꼴 넣기 | `fonts` | 켬 | 끄면 글자 모양·줄바꿈이 달라질 수 있다 |
| 안쪽 화면도 저장 | `frames` | 켬 | 같은 출처 iframe 을 `srcdoc` 으로 중첩 캡처 (3단계까지) |
| 열 때 보던 위치로 | `restoreScroll` | 켬 | 끄면 출력에 스크립트가 하나도 없다 |
| 크기 그대로 고정 | `pin` | 켬 | 표·사진 크기를 원본 기준으로 못박음 |

## 언어

`_locales/ko`, `_locales/en` 두 벌이고 브라우저 언어를 따라간다(기본 한국어).
팝업 문구는 `data-i18n` 속성으로 표시하고 `chrome.i18n` 이 채운다.
확장 밖에서 `popup.html` 을 직접 열었을 때는 `messages.json` 을 직접 읽어 미리보기가 된다.

```bash
node test/uishot.mjs ko,en     # 두 언어 × 라이트·다크로 촬영
```

## 동작 방식

### 1. 가시성 판정

요소마다 "지금 화면에 그려져 있는가"를 판정해 세 갈래로 나눈다.

| 상태 | 처리 | 이유 |
|---|---|---|
| `display:none` | 통째로 버림 | 자리를 차지하지 않으므로 지워도 레이아웃이 안 밀린다 |
| `visibility:hidden`, `opacity:0`, 조상이 투명 | 내용만 버리고 빈 껍데기로 | 자리는 차지하므로 크기를 유지해야 한다 |
| 뷰포트 밖 / `overflow` 클립 밖 | 빈 껍데기 | 〃 |
| 다른 요소에 가려짐 | 빈 껍데기 | 모달 뒤에 깔린 본문 등 |
| `.sr-only` 관용구 (`clip:rect(...)`, 1px 상자) | 빈 껍데기 | 스크린리더 전용 텍스트가 딸려오지 않게 |

껍데기가 연달아 나오면 하나로 접어서, 안 보이던 영역은 빈 상자 한 개로 줄어든다.

가림 판정은 그 지점을 덮은 요소들을 위에서부터 훑되 **실제로 뭔가를 칠하는** 첫 요소만 센다.
클릭 영역을 넓히려고 얹어둔 투명 레이어는 위에 있어도 아래 글자를 가리지 않기 때문이다.

### 2. 스타일

원본 CSS 는 한 줄도 가져오지 않는다. 대신 `getComputedStyle` 결과를 **태그별 UA 기본값**과
**부모에서 상속받는 값** 두 가지와 비교해 달라진 선언만 남긴다. 그 결과 애니메이션, `:hover`,
미디어쿼리, 쓰이지 않은 규칙이 전부 없어지고 화면에 찍힌 상태만 남는다.
같은 선언 묶음은 클래스 하나로 합치고, `::before`/`::after` 도 함께 옮긴다.

### 3. 리소스

이미지·웹폰트·배경 이미지를 data URI 로 embed 한다. 교차 출처 리소스는 콘텐츠 스크립트가
직접 못 가져오므로(MV3) 서비스 워커가 대신 받아온다. `<canvas>` 와 `<video>` 는
**그 순간의 픽셀**을 떠서 `<img>` 로 바꾼다. 입력값·체크 상태·선택 항목도 그대로 보존된다.

### 4. 스크롤 위치

껍데기 높이가 원본과 몇 px 어긋날 수 있어서, 눈에 띄는 블록 몇 개의 원본 좌표를 심어두고
파일을 열 때 오차의 중앙값만큼 보정한다. 이 복원용 초소형 스크립트 하나를 빼면
출력 파일에 스크립트가 전혀 없다. `freeze` 를 켜면 이것마저 빼고, 대신 문서를 스크롤한 만큼
음수 마진으로 끌어올려 CSS 만으로 잘라낸다.

## 여기서 배운 것

"계산된 스타일만 옮기면 된다"는 단순한 발상에 함정이 많았다. 전부 실제로 화면을 망가뜨린 것들이다.

**UA 스타일시트는 속성에 반응한다.** `href` 없는 `<a>` 에는 밑줄 규칙이 안 걸리므로,
기본값을 잴 때 `href`·`type`·`checked` 를 그대로 복사해서 재야 한다. 안 그러면 원본의
`text-decoration:none` 이 "기본값과 같다"며 누락되고, 저장본에서 링크에 밑줄이 되살아난다.

**UA 규칙은 상속을 이긴다.** `h2` 의 `font-size` 가 부모와 같다고 생략하면 출력에서
UA 의 `h2{font-size:1.5em}` 이 되살아난다. UA 가 손댄 속성은 항상 적어야 한다.

**두께는 스타일과 짝이다.** 원본이 `border-width:0` 이면 계산값이 기본값과 같아 생략되는데,
`border-style:solid` 만 남으면 두께가 initial 값 `medium`(3px) 으로 해석돼
없던 테두리가 사방에 생기고 그만큼 레이아웃까지 밀린다.

**`getComputedStyle().width` 는 이미 `box-sizing` 을 반영한 값이다.** content box 값인 줄 알고
padding 을 더하면 요소가 그만큼 부푼다.

**표 셀의 `width` 는 무시되지 않는다.** 표 레이아웃 알고리즘에 강한 힌트로 작동하므로
반드시 넣어야 원본 열 너비가 재현된다. 폭이 무시되는 건 행·행그룹뿐이다.

**계산값은 반올림된 값이다.** 부모와 자식에 동시에 못박으면 자식 폭의 합이 부모를
0.001px 수준으로 넘어서고, `float` 옆에 들어가던 블록이 아래로 밀린다. `overflow:hidden` 이
걸려 있으면 그대로 잘려 글자가 사라진다. 못박는 값은 소수점 두 자리에서 내린다.
(`test/subpixel.html` 에 최소 재현이 있다.)

**`elementsFromPoint` 는 히트테스트다.** `pointer-events:none` 요소를 건너뛰므로 스택에서
자기 자신을 못 만나고 뒤의 형제 배경을 만나 "가려짐"으로 오판한다. `pointer-events` 는
상속되므로 부모 하나만 걸려도 서브트리 전체가 날아간다.

**`overflow:hidden` 조상이 `static` 이면 절대배치 자손을 자르지 못한다.** 컨테이닝 블록이
아니기 때문이다. 이걸 모르고 자르면 열린 드롭다운이 빈 상자가 된다.

**폰트 수집은 계산된 `font-family` 를 기준으로 해야 한다.** `font-family` 스택에서 이름을
긁으면 폴백까지 들어와, 화면에 한 번도 안 그려진 웹폰트가 통째로 실린다.
실제로 한 캡처본은 2.55MB 중 93.7% 가 안 쓰이는 `@font-face` 였다.

**실패한 측정을 캐시하면 안 된다.** 기본값을 못 잰 태그를 빈 결과로 캐시하면 그 태그는
이후 계속 "기본값이 하나도 없는" 상태가 되어 요소마다 350여 개 속성이 쏟아진다.
파일이 수십 MB 로 부푸는데 오류는 하나도 안 남는다.

## 알려진 한계

- **교차 출처 iframe** (유튜브 임베드, 광고 등)은 내용을 읽을 수 없어 빈 상자로 남는다.
- **closed shadow root** 안의 내용은 접근 불가라 빠진다. open shadow root 는 처리한다.
- 뷰포트 **밖** 문단 내부의 인라인 흐름은 무너진다 (화면에 안 보이는 영역이라 무해).
- 리소스 서버가 referer 를 따지면 일부 이미지를 못 가져온다. 이때는 `alt` 까지 지워서
  깨진 이미지 아이콘 대신 빈 자리로 남긴다.
- 로그인 상태에서 보이는 이미지도 파일에 그대로 담긴다. 파일을 남에게 보낼 때 주의.

## 개발

```bash
node test/run.mjs                       # 합성 페이지로 27개 항목 검증
node test/live.mjs <URL> <이름> [스크롤Y] [overlay|freeze]
node test/diff.mjs <URL> <이름>          # 같은 id 요소의 좌표를 비교해 레이아웃 오차 추적
node test/probe.mjs <URL> '<JS 식>'      # 실제 페이지에서 식을 평가 (원인 추적용)
node test/uishot.mjs ko,en              # 팝업 UI 를 언어 × 라이트/다크로 촬영
```

의존성 없이 Node 22+ 내장 WebSocket 으로 Chrome DevTools Protocol 에 직접 붙는다.
`live.mjs` 는 확장 없이 페이지에 스크립트를 주입하는 방식이라 `--disable-web-security` 로
교차 출처 fetch 를 흉내 낸다.

`diff.mjs` 는 세로(`Δtop`)뿐 아니라 **가로(`Δleft`)** 도 본다. 레이아웃이 밀리는 버그는
대부분 "어떤 요소부터 좌표가 틀어지는가"를 찾으면 원인이 바로 드러난다.

### 아이콘

**잘라내기 표시가 HTML 을 겨누는** 형태다. 네 모서리 브래킷은 캡처의 보편 기호이고,
그 안에 든 글자가 무엇을 잡아내는지 말한다.

```bash
python3 scripts/make_icons.py orange icons   # 색만 바꿔 다시 뽑는다
node test/render_text.mjs                    # 글자 마스크 재생성 (폰트는 자동으로 받아온다)
```

- **크기마다 다르게 그린다.** 16px 에서 브래킷 안쪽은 9px 폭이라 네 글자가 물리적으로 안 들어간다.
  32px 부터는 `H` 한 글자로 바꾼다. 축소가 아니라 다시 그리는 것이다.
- **글자는 폰트를 렌더한 마스크를 쓴다** (`assets/mask-*.png`). 획으로 흉내내면 자간과 꺾임이
  어긋나고, 폰트 파일을 심으면 재현이 안 된다.
- 배경은 애플 아이콘 문법 — 모서리는 원호가 아닌 연속 곡률(초타원 n=5), 수직 그라데이션, 상단 광택.
- 팝업 헤더 로고는 별도 SVG 를 그리지 않고 `icons/icon32.png` 를 그대로 쓴다. 두 그림이 어긋날 여지를 없앴다.

### 패키지

```bash
./scripts/package.sh          # dist/page-capture-to-html-<버전>.zip
```

확장이 실제로 쓰는 파일만 담는다. `test/`·`scripts/`·`assets/` 는 개발용이라 빠진다.

## 파일 구조

```
manifest.json          매니페스트 (MV3)
_locales/ko, en        번역 문구
content.js             캡처 엔진 — 가시성 판정, 스타일 diff, 리소스 인라인
background.js          service worker — 교차 출처 리소스 대행 fetch
popup.html / popup.js  팝업 UI
icons/                 툴바·스토어 아이콘 16·32·48·128px
fonts/                 Pretendard 라틴 서브셋 29KB (전체는 2,009KB)
assets/                아이콘 글자 마스크 (생성용, 확장에는 안 들어감)
scripts/               아이콘 생성기, 패키지 스크립트
test/                  검증 스크립트와 픽스처
```
